*Identity & Access · Published October 11, 2026*

Imagine an organization with email, learning tools, and other apps. It needs a way to manage identities and control sign-in across them.

**Microsoft Entra ID** is Microsoft’s cloud-based identity and access management service. Its previous name was **Azure Active Directory**, or Azure AD.

It is one product in the wider Microsoft Entra family. Windows Server Active Directory is a separate technology; it was not renamed to Entra ID.

## What can it help with?
It manages users, groups, and application identities. It supports authentication and single sign-on: signing in once to access integrated applications, subject to their policies.

Capabilities such as Conditional Access, identity protection, and privileged identity management can add controls depending on the product, configuration, and license.

**A tenant** is an organization’s instance of the service, with its directory and settings.

## A LaxAIHub example
A possible design could use Entra ID for staff sign-in and evaluate Entra External ID for customer identities. The website would still enforce its own course and content permissions.

## Try it on paper
Draw an organization’s users, groups, and three apps. Mark who needs each app. Separate customer sign-in from staff administration.

**Remember: Entra ID helps manage identity; each application still needs correct access controls.**
